# concertOS
## Main Idea
The main idea of this project was to create a platform through which you could control micro-controller based devices in an unified manner,
each device running custom-made software that could be controlled by this platform. ConcertOS' responsability being managing state transitions,
(i.e. RGB stage lights that would change colors when the platform deemed it so).

By using ConcertOS as an abstract trigger for all sorts of devices, one could also abstract the source of the events that would trigger the
state transitions, such as another app, a timer, or even an AI agent.
